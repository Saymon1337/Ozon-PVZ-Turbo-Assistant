## 💡 Проблема и архитектурное решение

В ежедневной работе оператора Турбо ПВЗ Ozon возникают критические задачи:

1. **Сбои 2D-сканера маркировки («Честный Знак»)**:  
   При сканировании кодов DataMatrix сканер в режиме эмуляции клавиатуры передает системные комбинации клавиш (F12, Ctrl+U, Ctrl+Shift+I). Расширение перехватывает их на фазе Capture Phase, предотвращая зависание и срыв фокуса.

2. **Озон Полка: Пропущенные товары на отправку и ложные срабатывания**:  
   - **Фильтрация «Доставка Ozon»**: курьерская доставка клиентам («Доставка Ozon») ранее могла вызывать ложные оповещения. В версии 2.1.0 добавлен строгий фильтр, исключающий курьерскую доставку и отслеживающий строго отправку («Отправка», «Ozon Полка»);
   - **Кнопка перехода к отправке**: переход по целевому URL `https://turbo-pvz.ozon.ru/outbound/selection` с автоматической фокусировкой существующей вкладки или открытием новой;
   - **Синхронизация между вкладками**: при появлении отправлений свернутые вкладки обновляются в фоне, а при очистке полки — синхронно сбрасываются.

## ✨ Ключевые возможности

### 1. 🛡️ Модуль 1: PVZ Scanner Guard (Защита сканера «Честный Знак»)
- **Глобальный перехват на фазе Capture**: события клавиш F12, Ctrl+U, Ctrl+Shift+I/J/C блокируются до вызова DevTools;
- **100% сохранение полезных данных**: криптохвосты маркировки, нажатия Enter и буфер обмена передаются в форму выдачи без потерь;
- **Мгновенный подсчет без задержек**: счетчик предотвращенных сбоев сохраняется в `chrome.storage.local` и отображается в попапе;
- **Кроссплатформенность**: одинаково защищает на русской и английской раскладках (Windows, macOS, Linux).

### 2. 🔔 Модуль 2: Shelf & Dispatch Alert (Озон Полка и отправка)
- **Точная детекция отправки**: распознавание целевых индикаторов («Отправка», «Ozon Полка», ссылки `/outbound/selection`);
- **Защита от ложных срабатываний**: блок «Доставка Ozon» явно игнорируется, устраняя паразитные тревоги;
- **Быстрый переход в цепочку Отправка → Ozon Полка**: кнопка `[ 📦 Открыть «Отправку» ]` на плашке и в попапе ведет на `https://turbo-pvz.ozon.ru/outbound/selection` с фокусом на окно браузера;
- **Двусторонняя мульти-вкладочная синхронизация**: фоновые вкладки безопасно подтягивают актуальное состояние склада;
- **Безопасное мигание заголовка**: заголовок `(🚨 ОТПРАВКА: X шт)` мигает только при свернутом окне и восстанавливается при возврате.

### 3. 🔊 Аудио-движок Web Audio API (10 звуковых сигналов)
Синтез звука в выделенном Offscreen Document с нулевой нагрузкой и 100% защитой от ограничений браузера:
1. `default` — **Стандартный звонок (D5 → A5)** (двухтональный колокол с богатыми гармониками);
2. `soft_chime` — **Мягкий колокольчик** (теплый мажорный перезвон);
3. `double_beep` — **Двойной бип** (четкий электронный сигнал для шумного помещения);
4. `urgent_siren` — **Срочная сирена** (двойной свип повышенного внимания);
5. `melodic_chord` — **Мелодичный аккорд** (гармоничный мажор До-мажор);
6. `retro_signal` — **Ретро-сигнал (8-bit)** (ностальгический аркадный звук);
7. `crystal_bell` — **Кристальный звон** (чистый звон хрустального стекла);
8. `short_click` — **Короткий щелчок** (лаконичный тихий сигнал);
9. `subtle_ping` — **Нежный пинг** (одиночный мягкий колокольчик);
10. `radar_sonar` — **Радар / Сонар** (глубокий гидролокационный импульс).
- **Регулировка громкости**: от 0 до 100%;
- **Настройка интервала повтора**: от 1 до 30 минут с отображением значения;
- **Лимит повторений**: без ограничений, 1 раз, 3, 5 или 10 раз.

### 4. ✨ Настраиваемое мерцание и анимация плашки
Все параметры плашки динамически управляются через CSS-переменные без перезагрузки страниц ПВЗ:
- **5 стилей анимации**:
  - `pulse` — Пульсация (фирменное свечение Ozon);
  - `glow` — Мерцание рамки / неоновое свечение;
  - `blink` — Плавное мигание прозрачностью;
  - `shake` — Легкое ритмичное встряхивание;
  - `none` — Без анимации (статичная плашка).
- **Плавные CSS-переходы**: анимированное появление и исчезновение;
- **Регулировка частоты**: от 0.4 до 3.0 секунд;
- **Регулировка яркости / интенсивности**: от 20% до 100%.

### 5. 🎛️ Современный пульт управления (Popup) с Live Preview
- **Двухэкранный интерфейс**: быстрое переключение между вкладками `⚡ Главная` и `⚙️ Расширенные настройки`;
- **Live Preview в реальном времени**: интерактивный блок прямо в окне расширения сразу демонстрирует выбранную анимацию, скорость и яркость плашки;
- **Фирменная палитра Ozon**: синий (`#005bff`) и малиновый (`#f91155`) акценты;
- **Светлая и темная тема**: переключение `🌙 / ☀️` с плавным переходом;
- **Кнопка сброса настроек по умолчанию**: возврат рекомендованных параметров в один клик.

## 📦 Установка в браузер

Подходит для любого Chromium-браузера (**Google Chrome**, **Яндекс Браузер**, **Opera**, **Microsoft Edge**):

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Saymon1337/Ozon-PVZ-Turbo-Assistant.git
   ```
2. Откройте в браузере: `chrome://extensions/`
3. Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку проекта.
5. Нажмите F5 на уже открытых вкладках Турбо ПВЗ для применения скриптов.

## 🧪 Локальное тестирование (test.html)

Файл `test.html` содержит интерактивный стенд для проверки всех возможностей:
1. Откройте `test.html` в браузере;
2. Нажмите `+1 Товар на отправку` — появится анимированная плашка и прозвучит выбранный звук;
3. Нажмите `+1 Заказ в «Доставка Ozon»` — убедитесь, что расширение **не реагирует** на доставку;
4. Нажмите кнопку на плашке `📦 Открыть «Отправку»` — проверится переход на `https://turbo-pvz.ozon.ru/outbound/selection`;
5. Нажмите `🛡️ Симулировать сбой F12` — перехват предотвратит открытие DevTools и увеличит счетчик сбоев в расширении.
