## 💡 Проблема и архитектурное решение

В ежедневной работе оператора Турбо ПВЗ Ozon возникают две главные боли:

1. **Сбои 2D-сканера маркировки («Честный Знак»)**:  
   При сканировании кодов DataMatrix сканер в режиме эмуляции клавиатуры передает разделители групп GS1 (ASCII 29 / FNC1). Движок Chromium ошибочно интерпретирует определенные комбинации как системные горячие клавиши:
   - `F12` — непроизвольно открывает тяжелые инструменты разработчика (DevTools);
   - `Ctrl + U` — открывает исходный HTML-код страницы;
   - `Ctrl + Shift + I / J / C` — запускает инспектор элементов или консоль.  
   *Страница теряет фокус, зависает, а клиенты ждут.*

2. **Пропущенные товары на отправку и рассинхронизация вкладок**:  
   Оператор параллельно обслуживает нескольких клиентов в 3–4 вкладках. Когда в системе появляется посылка на отправку (или возврат курьеру), боковое меню в свернутых фоновых вкладках SPA-приложения Ozon не обновляется, пока страницу не перезагрузить вручную. В результате отправления накапливаются и задерживаются.

**Решение**: «Ozon PVZ: Turbo Assistant» перехватывает паразитные хоткеи на фазе погружения (Capture Phase), сохраняя поток данных штрихкодов, и организует надежную двустороннюю шину синхронизации между всеми открытыми вкладками с громким Web Audio оповещением.

## ✨ Ключевые возможности

### 1. 🛡️ Модуль 1: PVZ Scanner Guard (Защита сканера)
- **Глобальный перехват на фазе Capture**: события клавиш блокируются до того, как системные обработчики Chromium откроют DevTools;
- **100% сохранение полезных данных**: символы маркировки, криптохвосты, нажатия `Enter` и буфер обмена передаются в форму выдачи без потерь;
- **Мгновенный подсчет без задержек**: счетчик сбоев в реальном времени сохраняется в `chrome.storage.local` и сразу транслируется в пульт управления;
- **Кроссплатформенность и раскладки**: одинаково защищает на русской и английской раскладках клавиатуры, а также на Windows, macOS и Linux.

### 2. 🔔 Модуль 2: Shelf & Dispatch Alert (Оповещение об отправке)
- **Красная плашка на весь экран**: сверху страницы разворачивается пульсирующий баннер с точным количеством отправлений и кнопкой `[ 📦 Открыть «Отправку» ]` для перехода в раздел в один клик;
- **Мощный пробивной колокольный звон (Boost 2.5x)**:  
  Двухтональный сигнал `D5 -> A5` (587 Гц -> 880 Гц) синтезируется на лету через **Web Audio API** с обертонами 1174, 1760 и 2637 Гц и аппаратным лимитером. Никаких внешних MP3-файлов — чистый, пронзительный звон, отлично слышимый даже на тихих динамиках ноутбуков;
- **Без звука в свернутых вкладках**: фоновые вкладки строго заглушены (`document.hidden`), звук звучит только в той вкладке, где оператор работает в данный момент (без раздражающего эха);
- **Двусторонняя мульти-вкладочная синхронизация**:
  - **Когда товары появились**: свернутые вкладки автоматически и бесшумно перезагружаются в фоне. При переключении между клиентами бейдж уже на месте;
  - **Когда товары отправлены**: сброс происходит мгновенно во всех вкладках, а фоновые вкладки очищаются от старого бейджа;
  - **Защита активного экрана**: вкладка, на которой оператор в данный момент сканирует заказ, **никогда не перезагружается принудительно**, исключая срыв обслуживания;
  - **Защита от зацикливания**: интеллектуальный кулдаун (12 секунд через `sessionStorage`) исключает частые перезагрузки;
- **Умный шедулер**: повторный сигнал звучит строго по расписанию (каждые 2, 5, 10 или 15 минут), без ложных повторов;
- **Безопасное мигание заголовка**: заголовок вкладки `(🚨 ОТПРАВКА: X шт)` мигает только при реальном наличии товаров и восстанавливается при возврате.

### 3. 🎛️ Современный пульт управления (Popup)
- **Светлая и темная тема**: мгновенное переключение по кнопке `🌙 / ☀️` в шапке с запоминанием выбора;
- **Независимые тумблеры**: раздельное включение/выключение защиты сканера и оповещений об отправке;
- **Живая статистика**: крупный счетчик предотвращенных сбоев сканера с кнопкой мгновенного сброса;
- **Индикатор статуса полки**: статусное табло `Полка пуста` или `Требует отправки`;
- **Регулятор громкости**: ползунок до 100% с кнопкой тестирования звука прямо в попапе;
- **Высококонтрастная графика**: легко читаемые шрифты и стильный дизайн в темном и светлом оформлении.

## 📦 Установка в браузер

Подходит для любого Chromium-браузера (**Google Chrome**, **Яндекс Браузер**, **Opera**, **Microsoft Edge**):

1. Скачайте проект или клонируйте репозиторий:
   ```bash
   git clone https://github.com/Saymon1337/Ozon-PVZ-Turbo-Assistant.git
   ```
2. Откройте страницу управления расширениями:
   - В Google Chrome: `chrome://extensions/`
   - В Яндекс Браузере: `browser://tune/` или `chrome://extensions/`
3. Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) слева вверху.
5. Выберите папку с файлами расширения.
6. ⚠️ **Важно**: Если вкладки Турбо ПВЗ уже были открыты, **обновите их (нажмите F5)**, чтобы расширение внедрилось в страницу.

## 🧪 Локальное тестирование (test.html)

В состав проекта входит полноценный интерактивный эмулятор интерфейса Турбо ПВЗ — `test.html`:

1. В `chrome://extensions/` на карточке расширения нажмите **«Сведения»** (Details).
2. Включите опцию **«Разрешить открывать файлы по ссылкам»** (Allow access to file URLs).
3. Откройте файл `test.html` в браузере (можно открыть в 2–3 вкладках для проверки синхронизации).
4. **Тест отправки**:
   - Нажмите `+1 Товар на отправку` — появится красная плашка и прозвучит громкий сигнал;
   - Переключитесь на вторую вкладку — она уже обновилась в фоне, и счетчик отображает товары;
   - Нажмите `Сбросить в 0` — плашка закроется во всех вкладках.
5. **Тест защиты сканера**:
   - Нажмите физическую клавишу `F12` (или кнопку `🛡️ Симулировать сбой F12`) — вызов DevTools заблокируется, а счетчик сбоев в расширении вырастет.

## ⚙️ Технические детали

| Параметр | Значение |
|---|---|
| **Платформа** | Google Chrome Extensions Manifest V3 |
| **Permissions** | `storage` (локальное хранилище настроек и счетчиков) |
| **Host Permissions** | `*://turbo-pvz.ozon.ru/*`, `*://*.turbo-pvz.ozon.ru/*`, `file:///*`, `localhost` |
| **Звуковой движок** | Web Audio API (двойной осциллятор Triangle + Sine, DynamicsCompressor, Boost 2.5x) |
| **Синхронизация** | `chrome.storage.onChanged` + `chrome.runtime.sendMessage` + `sessionStorage` cooldown |
| **Наблюдатель DOM** | `MutationObserver` (дебаунс 500 мс) + резервный опрос (3 сек) |
| **Изоляция памяти** | Нулевая нагрузка на сторонние сайты (Google Таблицы, CRM, Docs) |
